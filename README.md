# 오디세이

오디세우스의 귀향을 따라가는 **3D 쿼터뷰 로그라이크**. 스테이지마다 원형 투기장 하나와 보스 하나, 사이사이에 선택지.

결은 *Shape of Dreams* 쪽을 본다 — 쿼터뷰 액션 로그라이트, 고른 것들이 쌓여 빌드가 되는 재미, 바닥에 크게 깔려 눈으로 읽히는 예고.

| | |
|---|---|
| **종류** | 3D 액션 로그라이크 (소울라이크 리듬 · 로스트아크식 쿼터뷰) |
| **엔진** | three.js — 물리엔진 없음. 전투는 XZ 평면에서 원·부채꼴 거리 계산으로 본다 |
| **로컬 실행** | `npm install && npm run dev` → http://localhost:5180 |
| **지금 단계** | **0단계 — 전투 코어 시험장.** 스테이지도 로그라이크도 아직 없다 |

## 판 골라서 해보기

```bash
npm run dev      # → http://localhost:5180
```

저승을 지난 뒤라면 유물 하나. 맨몸으로 보고 싶으면 목록의 체크박스나 `?bare=1`.

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` (또는 방향키) | 이동 |
| 마우스 | 조준. 바닥의 조준점이 곧 커서다 |
| 좌클릭 | 칼. 3타 콤보 (12 → 14 → 28) |
| 우클릭 | 활. 꾹 누르면 차징 (9 → 26, 꽉 채우면 관통) |
| `Space` | 구르기. 3.7 유닛 / 0.38초, 충전 3회, 하나 차는 데 3.4초 |
| `Shift` | 중격. 쌓인 **기세**를 전부 태운다 (칸마다 피해 +14, 무력화 +9) |
| `E` | 함성. 동료를 한꺼번에 몰아붙인다 — 미는 힘은 **남은 사람 수**를 따른다 |
| `Q` | 막기. **맞기 직전(0.18초)** 에 누르면 쳐낸다 — 피해 0, 적의 무력화를 크게 민다 |
| `1` `2` `3` | 레벨업 선택 |
| `R` / `Q` | 다시 시작 / 적 추가 소환 (시험용) |

## 전투 규칙

설계의 전부가 여기 있다.

- **액션은 프레임 데이터다.** `startup`(예고) → `active`(판정) → `recovery`(후딜). 플레이어도 적도 보스도 같은 시스템을 쓴다. 소울라이크의 리듬(예고 → 회피 → 반격)이 이 세 숫자에서 나온다.
- **적은 예고에 몸을 맡긴다.** 시전이 시작되면 그 자리에 장판을 깔고 위치도 방향도 잠근다. 판정은 현재 위치가 아니라 잠긴 위치에서 본다. "빨간 데 서 있으면 맞는다"가 지켜져야 회피가 실력이 된다.
- **구르기 무적은 가운데 구간만.** 0.34초 중 0.03~0.25초. 구르기 전체가 무적이면 실력이 아니라 버튼 연타가 된다. 거리(3.0)와 시간(0.34초)은 같이 움직인다 — 거리만 줄이면 걷는 것보다 느려져서 구르는 맛이 죽는다.
- **구르기는 후딜만 끊는다.** 예고와 판정 구간은 책임진다. 3타를 지를지 말지가 고민이 되어야 근접전이 재미있다.
- **입력 버퍼 0.22초.** 후딜 중에 누른 입력을 들고 있다가 캔슬 창이 열리면 꺼내 쓴다. 이게 없으면 조작이 통째로 뻑뻑하다.
- **기세와 중격.** 칼이 닿으면, 구르기로 실제 공격을 흘리면 기세가 한 칸씩 쌓인다(최대 4). 중격은 그걸 전부 태운다. 쌓아야만 쓸 수 있는 한 방이 하나 있어야 근접전에 계좌가 생긴다 — 없으면 3타를 계속 돌리는 일이 된다.
- **무력화.** 보스 체력 밑의 청록 게이지. 중격과 함성이 민다. 다 차면 무릎을 꿇고 그 동안 두 배로 맞는다. 한 번 무너뜨릴 때마다 다음 벽이 높아져서 같은 기술만 돌릴 수 없다.
- **동료는 숫자가 아니다.** 남은 사람 수가 **곁에 서는 인원**(400/120 을 경계로 셋·둘·하나)과 **함성의 위력**을 정한다. 보스의 장판에 걸린 동료는 주저앉고, 곁에 1.6초 서 있으면 일어난다. 12초 안에 못 일으키면 그를 따르던 마흔이 배로 못 돌아온다. 함성으로 부른 동료는 장판을 못 피한다 — 그게 그 기술의 값이다.
- **막기와 쳐내기, 그리고 자세.** 방어가 구르기 하나뿐이면 모든 예고의 정답이 같아진다. 누르고 있으면 피해의 30%만 몸으로 받고 나머지는 자세로 받되, 자세가 다 차면 1.1초 굳는다 — 계속 막고만 있을 수는 없다. 맞기 직전 0.18초 안에 누르면 **쳐낸다**: 피해도 자세도 0 이고 적의 무력화가 크게 밀린다. 방어가 이기는 길이어야 방어에 손이 간다.
- **히트스톱.** 맞는 순간 0.05~0.11초 프레임을 얼린다. 타격감의 8할. 시뮬레이션만 멈추고 연출은 실시간으로 흐른다.

## 여덟 개의 판

**한 판은 두 구간이다 — 뱀서식 웨이브로 자라고, 그 끝에서 보스를 만난다.**
웨이브에서 모은 전리품과 성장을 그대로 들고 보스방으로 넘어간다.
구간마다 땅도 빛도 다르다 (해안에서 싸우다 동굴로 들어가는 식).

|---|---|---|---|

보스 여덟, 패턴 50여 개. **전부 데이터다** (`enemy/bosses.js`) — 패턴 목록과 페이즈만 쓰면 보스 하나가 된다.
보스도 잡몹과 같은 규칙을 따른다: 시전이 시작되면 위치와 방향을 잠그고 장판을 깐다.
보스라고 예외를 두면 "분명히 피했는데 맞았다"가 되고, 그 순간 소울라이크가 아니게 된다.

**그로기** — 큰 기술 뒤에 멍해진다. 여기서 받는 피해가 2배 안팎이라, 반격 창을 잡는 게 곧 공략이다.

### 웨이브 구간

한 무더기 쏟고 다 잡을 때까지 기다리는 방식이 아니다. **처치 수에 따라 압박을 올리면서 계속 흘려보낸다.**
적은 늘 플레이어 반대편 가장자리에서 들어온다 — 등 뒤에 갑자기 생기면 억울하다.

## 성장

**기본값은 일부러 느리다.** 이동속도도 활 차징도 처음엔 답답하고, 모아서 푸는 게 이 게임의 성장이다. 기본값이 이미 쾌적하면 레벨업이 의미가 없어진다.

적이 죽으면 전리품이 떨어지고 반드시 플레이어에게 날아온다. 레벨이 오르면 시간이 멈추고 세 장 중 하나를 고른다.

### 등급 — 수치가 오르다 어느 순간 규칙이 바뀐다

선택지는 **칼 · 활 · 발** 세 계열로 나뉜다. 한 계열을 계속 파면 등급이 열린다.

| 등급 | 조건 | 바뀌는 것 |
|---|---|---|
| **일반** | — | 수치가 오른다 |
| **레어** | 같은 계열 2번 | 칼에 불이 붙는다 / 화살이 튕긴다 / 구르기가 적을 벤다 |
| **유니크** | 같은 계열 4번 + 레어 보유 | 불이 옮아붙는다 / 튕길수록 세진다 / 착지에 충격파 |
| **레전더리** | 같은 계열 6번 + 유니크 보유 | 3타가 불길이 된다 / 화살이 갈라진다 / 잔상이 한 번 더 지나간다 |

레어부터는 수치가 아니라 **플레이 방식**이 바뀐다. 불 빌드는 몰아서 태우고, 화살 빌드는 한 발로 여럿을 치고, 발 빌드는 구르기가 공격이 된다.

이름은 신화에서 가져온다. 오디세우스를 돕는 건 아테나이고 막는 건 포세이돈이라, **포세이돈의 이름으로 주는 은혜는 없다.**

| 기본값 | 값 | 올리는 선택지 |
|---|---|---|
| 이동속도 | 6.1 /초 | 날랜 발 +14% |
| 공격속도 | 1.0배 | 벼린 날 +13% |
| 활 차징 (꽉) | 1.05초 | 팽팽한 시위 +22% |
| 구르기 충전 | 3.4초 | 가벼운 몸 +24% |

공격속도는 **액션 시계를 배속하는 것**으로 구현했다 (`combat/action.js`). 예고·판정·후딜·캔슬 창이 한꺼번에 같은 비율로 따라와서, 어느 하나만 빨라져 밸런스가 어긋나는 일이 없다. 적의 예고 장판 길이도 같은 배수를 따른다.

## 에셋

캐릭터는 [Quaternius](https://quaternius.com) 의 **CC0** 팩을 쓴다 (`CREDITS.md`).
원본은 파츠 하나가 30MB 씩 하는데, 4K PNG 텍스처 때문이다.
쿼터뷰에서 캐릭터는 화면에 150px 남짓으로 나오므로 512 WebP 면 차고 넘친다.

```bash
node tools/prep-models.mjs     # art/ 원본 → public/models/ 최적화 산출물
```

| | 원본 | 산출물 |
|---|---|---|
| 캐릭터·장비 6개 | 각 30 MB | 합계 720 KB |
| 애니메이션 | 43클립 7.4 MB | 10클립 845 KB |
| **게임 전체 (gzip)** | | **약 5.4 MB** |

> 한동안 이 표에 "1.3 MB" 라고 적혀 있었는데 틀린 값이었다. 실제로 재 보니
> **14.5 MB** 였고, 그중 9.1 MB 가 쓰지도 않는 원본 PNG 여섯 장이었다
> (`athena.png` 2.1MB, `mainimage*.png` 4.9MB, `agamemnon*.png` 2.4MB —
> 전부 최적화된 .webp 가 이미 있는데 원본이 `public/` 에 같이 있었다).
> `art/src-png/` 로 옮겨서 5.4 MB 가 됐다.
>
> **이 숫자는 목표가 아니라 현황이다.** 웹 게임에서 5 MB 는 빠듯하지 않다.
> 에셋이 필요하면 가져오고, 대신 판마다 필요한 것만 그때 받는다
> (바닥 텍스처는 이미 그렇게 한다 — `#setGround`).

애니메이션은 필요한 클립만 남기고, **scale 채널 전부와 root·pelvis 를 뺀 translation 채널을
걷어낸다.** 뼈 길이는 변하면 안 되므로 회전만 있으면 된다. 이것만으로 대부분이 사라진다.
클립을 지울 때는 채널·샘플러를 명시적으로 dispose 해야 accessor 가 같이 없어진다 —
안 그러면 버린 클립의 데이터가 파일에 그대로 실린다.

플레이어도 적도 **같은 몸·같은 뼈대·같은 애니메이션**을 쓴다. 색조(`tint`)와 입은 조각만 다르다.
재질은 캐릭터마다 클론해서 갖는다 — 공유하면 한 마리가 맞을 때 전부 같이 번쩍인다.

무기·투구·망토는 본에 매단다. 본 축은 엔진마다 다르므로(UE 릭은 뼈가 X 축을 따라 뻗는다)
바인드 포즈에서 본 회전을 한 번 상쇄하고 건다. 상쇄값은 고정 로컬 오프셋이라
애니메이션이 돌면 프롭도 같이 따라간다.

모델이 하나도 없어도 게임은 돌아간다. `src/render/figure.js` 의 코드 인체로 넘어간다.

## 투사체

전부 같은 화살 메시를 쓰면 던지는 양도 파이어볼도 화살로 보인다. 일곱 가지로 나눴다.

| 종류 | 생김새 | 쓰는 곳 |
|---|---|---|
| `arrow` | 살대 · 청동 촉 · 깃 셋, 회전 | 플레이어 활, 키코네스 궁수, 텔레고노스 |
| `fire` | 밝은 속 + 일렁이는 겉 + 후광, 불티를 흘린다 | 키르케 파이어볼, 불의 파도 |
| `orb` | 매끈한 알에 고리가 돈다 | 세이렌의 노래 |
| `water` | 늘어진 물방울 | 카리브디스 |
| `rock` | 구르며 날아가는 돌덩이 | 바위 비 |
| `sheep` | 털뭉치 몸 · 머리 · 다리 넷, 뒹굴며 난다 | 폴리페모스 |
| `spear` | 긴 자루에 청동 날 | 투창 |

세 겹으로 만든다.

1. **꼬리 궤적** (`combat/trail.js`) — 지나온 자리 18점을 기억했다가 카메라를 향한 띠로 잇는다.
   폭은 천천히 줄고 밝기는 빨리 죽는다. 선형으로 줄이면 쐐기처럼 딱딱해 보인다.
   카메라 쪽으로 곧장 날아오면 진행 방향과 시선이 나란해져 폭이 0 이 되므로, 그때는 위쪽을 기준으로 잡는다.
2. **입자** (`render/particles.js`) — 불티·물방울·돌조각. Points 하나에 몰아 그린다.
   투사체마다 메시를 만들면 탄막 서른 발에서 드로우콜이 터진다.
3. **발사 섬광과 착탄** — 어디서 날아왔고 어디서 터졌는지가 눈에 남아야 한다.

             maze(저승의 길과 벽) · underworld(걸어 들어가 부르고 쫓겨 나오는 순서)

             boss·bosses(패턴 데이터) · bossparts(외눈·여섯 머리·아가리·날개)

- 카메라 리그는 `render/world.js`의 `CAMERA_RIG` 하나로 모여 있다. 스테이지마다 거리·각도·FOV 만 갈아끼우면 된다.
- 지금 모델은 전부 코드로 만든 그레이박스다. 나중에 GLTF 로 갈아끼울 수 있게 액터와 시각 표현을 분리해 뒀다.

## 배포 전에 지울 것

**시험용 무적이 켜져 있다.** 화면 위쪽에 빨간 `무적 켜짐 — G 로 끄기` 표시가
떠 있으면 켜진 것이다. `G` 로 그 자리에서 끌 수 있고, 주소에 `?god=0` 을 붙여도 된다.

아예 걷어내려면 세 군데를 지운다:

1. `src/main.js` — `this.setGod(...)` 호출과 `?god=` 읽기
2. `src/main.js` — `setGod()` 메서드, `KeyG` 키 바인딩, `jumpTo` 의 `p.god = this.god`
3. `src/combat/actor.js` — `hurt()` 안의 `if (this.god)` 블록과 필드 선언
