# 오디세이

오디세우스의 귀향을 따라가는 **3D 쿼터뷰 로그라이크**. 스테이지마다 원형 투기장 하나와 보스 하나, 사이사이에 선택지.

| | |
|---|---|
| **종류** | 3D 액션 로그라이크 (소울라이크 리듬 · 로스트아크식 쿼터뷰) |
| **엔진** | three.js — 물리엔진 없음. 전투는 XZ 평면에서 원·부채꼴 거리 계산으로 본다 |
| **로컬 실행** | `npm install && npm run dev` → http://localhost:5180 |
| **지금 단계** | **0단계 — 전투 코어 시험장.** 스테이지도 로그라이크도 아직 없다 |

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` (또는 방향키) | 이동 |
| 마우스 | 조준. 바닥의 조준점이 곧 커서다 |
| 좌클릭 | 칼. 3타 콤보 (12 → 14 → 28) |
| 우클릭 | 활. 꾹 누르면 차징 (9 → 26, 꽉 채우면 관통) |
| `Space` | 구르기. 충전 3회, 하나 차는 데 1.55초 |
| `R` / `Q` | 다시 시작 / 적 추가 소환 (시험용) |

## 전투 규칙

설계의 전부가 여기 있다.

- **액션은 프레임 데이터다.** `startup`(예고) → `active`(판정) → `recovery`(후딜). 플레이어도 적도 보스도 같은 시스템을 쓴다. 소울라이크의 리듬(예고 → 회피 → 반격)이 이 세 숫자에서 나온다.
- **적은 예고에 몸을 맡긴다.** 시전이 시작되면 그 자리에 장판을 깔고 위치도 방향도 잠근다. 판정은 현재 위치가 아니라 잠긴 위치에서 본다. "빨간 데 서 있으면 맞는다"가 지켜져야 회피가 실력이 된다.
- **구르기 무적은 가운데 구간만.** 0.44초 중 0.04~0.32초. 구르기 전체가 무적이면 실력이 아니라 버튼 연타가 된다.
- **구르기는 후딜만 끊는다.** 예고와 판정 구간은 책임진다. 3타를 지를지 말지가 고민이 되어야 근접전이 재미있다.
- **입력 버퍼 0.22초.** 후딜 중에 누른 입력을 들고 있다가 캔슬 창이 열리면 꺼내 쓴다. 이게 없으면 조작이 통째로 뻑뻑하다.
- **히트스톱.** 맞는 순간 0.05~0.11초 프레임을 얼린다. 타격감의 8할. 시뮬레이션만 멈추고 연출은 실시간으로 흐른다.

## 구조

```
src/
  core/      loop(고정 60Hz 타임스텝) · input(버퍼) · math
  render/    world(씬·조명·쿼터뷰 리그·포스트프로세싱) · fx(장판·궤적·피해 숫자·흔들림)
  combat/    action(프레임 데이터) · hit(부채꼴·원·도넛 판정) · actor · projectile
  player/    player(이동·구르기·칼 3타·활 차징)
  enemy/     kikones(전사·궁수·허수아비)
  ui/        hud
```

- 카메라 리그는 `render/world.js`의 `CAMERA_RIG` 하나로 모여 있다. 스테이지마다 거리·각도·FOV 만 갈아끼우면 된다.
- 지금 모델은 전부 코드로 만든 그레이박스다. 나중에 GLTF 로 갈아끼울 수 있게 액터와 시각 표현을 분리해 뒀다.
- `window.__game` 으로 콘솔에서 상태를 만질 수 있다.

## 앞으로

0. **전투 코어** ← 지금 여기. 여기가 재미없으면 보스 아홉 마리를 만들어도 소용없다
1. 이스마로스 — 키코네스족 웨이브 + 3레벨 선택 (로그라이크 루프 완성)
2. 폴리페모스 — 보스 프레임워크 검증 (양 던지기 · 스윙 · 그로기 눈 찌르기 · 고함 스턴)
3. 유물과 선택지 메타, 스테이지 연결
4. 나머지 보스 — 라이스트리고네스 · 키르케 · 세이렌 · 스킬라/카리브디스 · 구혼자
5. 아트 · 사운드 · 포스트프로세싱 패스
6. 텔레고노스 (무한 체력, 입힌 피해량이 점수) + 순위 + 크레딧

## 스테이지 기획

| 스테이지 | 적 | 핵심 |
|---|---|---|
| 이스마로스 | 키코네스족 | 뱀서식 웨이브, 3레벨 로그라이크 |
| 폴리페모스의 동굴 | 키클롭스 | 양 던지기 · 스윙 · 그로기 눈 찌르기 → 이후 양 난사 · 고함 스턴 |
| 텔레필로스 | 라이스트리고네스 | 1페 전사2 궁수1 → 2페 전사이자 궁수 1마리 |
| 아이아이에섬 | 키르케 | 돼지 소환 · 파이어볼 · 돼지 회복 · 돼지 변신(이동 느려지고 마법 회피가 어려워짐) |
| 저승 | 아가멤논 | 유물 3택 1 — 밀랍(CC 무시·공속) / 메두사 방패(피1 생존·구르기 2회·주위 스턴) / 청동 창(투척·고공격력·짧은 쿨) |
| 세이렌의 바다 | 세이렌 | 탄막 매혹, 바닥으로 들어갔다 현재 위치로 솟음, 접촉 시 체력 흡수 |
| 메시나 해협 | 스킬라 / 카리브디스 | 스킬라=배 위 5개 머리 → 2페 단일 머리 / 카리브디스=소용돌이 탄막 회피 후 눈 공격 |
| 이타카 | 구혼자 | 무한히 달려드는 적 처리. 빠르고 닿으면 아프다 |
| 죽음 | 텔레고노스 | 오디세우스와 같은 무기·패턴, 모든 유물 보유. 무한 체력이라 이길 수 없고 입힌 피해량이 최고 점수 |
